# 钢铁前线 · 坦克大战 (Tank Assault)

一个纯 HTML + Canvas 实现的经典俯视角坦克大战游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- **目标**：守住屏幕底部的基地旗帜，击退一波波来袭的敌军坦克。
- **移动**：`WASD` 或方向键
- **射击**：`空格` 或 `J`
- **暂停**：`P`
- **开始 / 重新开始**：`空格` 或 `回车`

## 🧱 地形与机制

| 元素 | 说明 |
| --- | --- |
| 🧱 砖墙 | 可被子弹摧毁 |
| ⛓ 钢墙 | 无法摧毁，阻挡子弹与坦克 |
| 🌊 水域 | 坦克无法通行，子弹可穿过 |
| 🌲 草丛 | 坦克无法通行，子弹可穿过 |
| 🚩 基地 | 被敌人击中则游戏结束 |

## ✨ 特性

- 关卡随进度自动变化，敌人数量与强度递增
- 三种地图布局循环切换
- 敌人 AI：追踪玩家、随机转向、主动开火
- 道具掉落：生命 +1、护盾、连射、清屏
- 粒子爆炸特效、屏幕震动、漂浮得分文字
- 纯 Web Audio 音效（无外部音频文件）
- 响应式界面，桌面 / 移动均可运行

## 🚀 运行

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
